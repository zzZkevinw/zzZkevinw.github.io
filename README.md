# Kaiwen Zhu — Personal Website

Live at https://kaiwenzhu.com.

Built with [al-folio](https://github.com/alshedivat/al-folio), using upstream commit `2fec8d3a9c99450328cee59a6a6114e26055d86e` and its pinned plugin versions. The upstream MIT license is included in `LICENSE`.

## Edit content

- `_pages/about.md`: biography and homepage settings
- `_pages/publications.md` and `_bibliography/papers.bib`: publications
- `_pages/projects.md`: projects
- `_data/socials.yml`: social links
- `_config.yml`: name, domain, and theme settings
- `assets/img/profile.svg`: initials placeholder; replace with a personal photo when ready

Push to `main` to build and publish through GitHub Actions. Other branches build for validation without deploying. The custom domain and HTTPS remain configured in GitHub Pages.
